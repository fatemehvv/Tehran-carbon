## پیش از خواندن حکم‌ها

- **حاشیهٔ هم‌ارزی:** حکم‌های `evaluate_*` با حاشیهٔ موقت δ = 0.02 از `config.yaml` گرفته شده‌اند. قاعدهٔ پیش‌ثبت δ = max(0.02, 2 × SD_seed) است. SD_seed میانگین روی ۱۴۰۲ و ۱۴۰۳ و روی دو مدل `paper2_rq2_sage_v1` و نسخهٔ سه‌حوزه‌ای gated از `paper2_rq1_ablation_v1` است. نتیجه:
  - Spearman: SD_seed ≈ 0.0077، پس δ = **0.02**.
  - PR-AUC: SD_seed ≈ 0.0366، پس δ ≈ **0.073**.

  حکم‌های PR-AUC باید با این δ دوباره خوانده شوند. این عددها در نهایی کردن `preregistration_paper_v2.md` ثبت می‌شوند.
- **seedها:** پیش‌بینی مدل‌های عصبی میانگین ۵ seed است. ردیف‌های `part = seeds` اختلاف تک‌تک seedها را نشان می‌دهند. برای نمونه، در PA_H2 برای سال ۱۴۰۲، مزیت PR-AUC با میانگین seedها 0.037 است، ولی میانگین تک‌تک seedها 0.008 است (بازه 0.015− تا 0.043+).
- **PR-AUC:** فقط ۵ بلوک معتبر دارد، پس کمترین p ممکن 0.031 است و به α = 0.025 نمی‌رسد (`power/`).
