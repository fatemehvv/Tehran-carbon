# نسخهٔ دوم پایان‌نامه (`thesis_v2_chapters_1-5.docx`)

فایل `docs/thesis/thesis_v2_chapters_1-5.docx` نسخهٔ تازهٔ پایان‌نامه است و فایل‌های پیشین (`thesis_chapters_2-5.docx`، `thesis_chapters_3-5.docx` و فایل پرسش ۱ و ۲) دست نخورده‌اند. پایهٔ آن همان فایل کامل فصل‌های ۳ تا ۵ با اصلاح‌های داوری است (گام ۱ و ۲ پایین)، به‌علاوهٔ:

1. **جلد و چکیده‌ها**: عنوان «همجوشی داده‌های چندوجهی برای تحلیل پیش‌بینانۀ کاهش ردپای کربن در تهران»، نام دانشجو و استاد راهنما، چکیده و واژگان کلیدی فارسی و انگلیسی، و عنوان در سربرگ صفحه‌ها. دانشکده، گرایش، تاریخ، تقدیم و تشکر برای پر کردن شما مانده‌اند.
2. **فصل اول کامل** (متن در `content_v2.py`): ۱-۱ مقدمه تا ۱-۱۰ ساختار پایان‌نامه، با هدف اصلی، شش هدف فرعی، پنج فرضیه، چهار پرسش، محدوده و مفروضات، روش و تعریف‌ها.
3. **فصل دوم به‌روز** (`content_ch2.py`، بر پایهٔ `content.py` نسخهٔ نخست): بخش تازهٔ ۲-۳-۵ «شبکه‌های گراف در برابر رگرسیون مکانی و نقش شعاع دید»، افزوده‌هایی در NO₂ ماهواره‌ای، یادگیری ماشین کربن، شبکه‌های گراف آلودگی، ارزیابی مدل‌های مکانی و تهران؛ ۳۹ منبع تازه از مقالهٔ شاخهٔ `paper_TC`؛ ستون «رقیب با شعاع دید برابر» و دو ردیف تازه در شکل ۱؛ شش ردیف تازه در جدول ۱ (۴۳ مقاله).
4. **نتایج شاخهٔ `paper_TC` در فصل‌های ۳ تا ۵**:
   - بخش تازهٔ ۳-۴-۱۴ «بررسی‌های تکمیلی پرسش‌های اول و دوم»: شعاع دید، کنترل نشت، پنج بذر، عملگر فیزیکی بخشی، استنباط با بلوک‌های کم (آزمون دقیق جایگشت علامت، جک‌نایف، آزمون هم‌ارزی، هولم) و ویژگی‌های هدف؛
   - بخش تازهٔ ۴-۲-۹ با شکل ۹ (مهارت بر حسب شعاع دید، از `reach_curve.csv` با `fig_reach.py`)، جدول ۲۰ (مهارت بر حسب شعاع دید) و جدول ۲۱ (اختلاف شبکهٔ گراف با رقیب‌ها)؛
   - بحث ۴-۳-۱ و ۴-۳-۲ و ۴-۳-۶، نتیجه‌گیری پرسش‌های اول و دوم، نوآوری‌ها، محدودیت‌ها و پیشنهادها در فصل پنجم، چهار ردیف تازه در جدول خلاصه (جدول ۲۷)، و یک خانه از جدول پیامدهای سیاستی.
   - پرسش‌های سوم و چهارم دست نخوردند: ورودی‌های آن‌ها در دو شاخه یکی است.
5. **شماره‌گذاری دوباره**: شکل‌های ۹ به بعد یک شماره و جدول‌های ۲۰ به بعد دو شماره جلو رفتند، و همهٔ ارجاع‌های متن به آن‌ها هم؛ بخش‌های ۳-۴-۱۴ به بعد و ۴-۲-۹ به بعد یک شماره جلو رفتند. ارجاع‌ها به ترتیب نخستین ارجاع در کل پایان‌نامه (IEEE) دوباره شماره خوردند: ۱۶۶ منبع. هر ارجاع قدیمی فصل‌های ۳ تا ۵ پس از شماره‌گذاری به همان متن منبع پیشین اشاره می‌کند (بررسی خودکار: ۴۶ منبع، ۳۵ پاراگراف).
6. **فهرست مطالب، اشکال و جداول** از روی همهٔ عنوان‌ها و زیرنویس‌ها دوباره ساخته شدند و شمارهٔ صفحه از یک خروجی PDF لیبره‌آفیس آمد. یادداشت‌های قرمز قالب («فهرست را به‌روز کنید و این متن را حذف کنید») برداشته شدند. Word هنگام باز شدن می‌پرسد فیلدها به‌روز شوند یا نه: **بله** بزنید تا شمارهٔ صفحه‌ها با Word یکی شوند.

فهرست همهٔ منابع، محل ارجاع و دلیل آوردن منابع تازه: `docs/thesis/references_notes_v2.md`. فایل وارد کردن در Mendeley یا EndNote: `docs/thesis/references_v2.ris` (همهٔ منابعی که از پایان‌نامهٔ اولیه نبودند).

عددهای بخش‌های ۳-۴-۱۴ و ۴-۲-۹ از اجراهای بدون نشت با پنج بذر در `docs/paper/results_stageA` شاخهٔ `paper_TC` آمده‌اند و برای همین اندکی با عددهای بخش‌های ۴-۲-۵ تا ۴-۲-۸ (سه بذر، طرح اصلی) فرق دارند؛ این در متن گفته شده است.

## ساختن دوباره

پیش‌نیاز: Python 3 با Pillow و Matplotlib 3.11 یا تازه‌تر (برای شکل ۹؛ نسخه‌های قدیمی‌تر `arabic_reshaper` و `python-bidi` می‌خواهند)، LibreOffice، Poppler، Node با Playwright، و قلم Vazirmatn (`npm install vazirmatn`).

```bash
# 1) باز کردن فایل‌ها
mkdir -p build && cd build
unzip -q ../docs/thesis/thesis_chapters_3-5.docx -d full
unzip -q ../docs/thesis/thesis_chapters_3-5_RQ1-RQ2.docx -d rq12
# 2) اصلاح‌های داوری روی فایل کامل (همان گام نسخهٔ نخست)
python ../docs/thesis/ch2_source/port_review_fixes.py full rq12 full_fixed
# 3) شکل ۱ (ماتریس شکاف) و شکل ۹ (شعاع دید)
python ../docs/thesis/v2_source/make_figure.py node_modules/vazirmatn/fonts/ttf figure1.html
node ../docs/thesis/v2_source/shot.js "$PWD/figure1.html" figure1.png
python -c "from PIL import Image; Image.open('figure1.png').convert('RGB').save('figure1.jpg', quality=93)"
mkdir -p figs && python ../docs/thesis/v2_source/fig_reach.py ../docs/thesis/v2_source/reach_curve.csv node_modules/vazirmatn/fonts/ttf figs/fig_reach.png
# 4) فصل اول، فصل دوم، به‌روزرسانی فصل‌های ۳ تا ۵، شماره‌گذاری ارجاع‌ها، فهرست منابع و فایل RIS
python ../docs/thesis/v2_source/build_v2.py full_fixed final figure1.jpg figs references_v2.ris ../docs/thesis/v2_source/lit > build_log.json
# 5) فهرست مطالب و فهرست‌های شکل و جدول: ساختار، سپس شمارهٔ صفحه از خروجی PDF
python ../docs/thesis/v2_source/tocfix_v2.py structure final
(cd final && zip -qXrD ../thesis.docx .) && soffice --headless --convert-to pdf thesis.docx
python ../docs/thesis/v2_source/tocfix_v2.py pages final thesis.pdf
rm thesis.docx && (cd final && zip -qXrD ../thesis_v2_chapters_1-5.docx .)
# 6) یادداشت منابع
python ../docs/thesis/v2_source/notes_v2.py final references_notes_v2.md build_log.json
```

`reach_curve.csv` رونوشت `docs/paper/results_stageA/reach/reach_curve.csv` از شاخهٔ `paper_TC` است. شکل‌های ۱ و ۹ با کیفیت بالا برای اسلاید در پوشهٔ `figures/` هستند.

**نکتهٔ لیبره‌آفیس.** شمارهٔ پاورقی‌ها در قالب دانشگاه در هر صفحه از نو شروع می‌شود، و لیبره‌آفیس با برخی چیدمان‌های پاورقی در چنین سندی در حلقه می‌افتد و تبدیل به PDF تمام نمی‌شود. در این نسخه یک پاراگراف بخش ۲-۳-۱۰ (ناترر و همکاران) برای همین به دو پاراگراف تقسیم شد. اگر پس از ویرایش متن، تبدیل در گام ۵ بیش از یک دقیقه طول کشید، همین مشکل است: پاراگراف نزدیک محل گیر کردن را اندکی تغییر دهید. Word این مشکل را ندارد.
