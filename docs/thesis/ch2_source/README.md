# فصل دوم و ساخت فایل کامل پایان‌نامه (`thesis_chapters_2-5.docx`)

فایل `docs/thesis/thesis_chapters_2-5.docx` همان فایل کامل فصل‌های ۳ تا ۵ (`thesis_chapters_3-5.docx`، هر چهار پرسش) است، به‌علاوهٔ:

1. **اصلاح‌های داوری** که پیش‌تر فقط روی فایل پرسش ۱ و ۲ انجام شده بود (کامیت‌های `95b8124` و `fd456ca`): بخش ۳-۲ فقط تفکیک دادهٔ توسعه و ارزیابی را نگه می‌دارد؛ ابزارها و منابع داده در پاورقی نام برده می‌شوند و ارجاع نمی‌گیرند؛ متن OCO-2 و OCO-3 و جدول ۲؛ پاراگراف NO₂ به‌عنوان نشانگر؛ پاراگراف‌های شبکه و سهم مساحت؛ جملهٔ ویرز؛ حذف جمله‌های چکیده و آزمون‌های خودکار. پاراگراف‌هایی که فقط در فایل کامل هستند (شبیه‌ساز و یادگیری تقویتی) همان اصلاح را درجا گرفتند (مثلاً ارجاع جیم‌نیزیوم و استیبل‌بیس‌لاینز حذف و نامشان در پاورقی ماند). فهرست صحت‌سنجی ۳-۵ شش مورد دارد و عنوانش هم «شش سطح» شد.
2. **فصل دوم کامل** برای هر چهار پرسش (متن در `content.py`):
   - ۲-۱ مقدمه، ۲-۲ مبانی نظری (به‌علاوهٔ یادگیری تقویتی، فرایند تصمیم مارکوف مقید، مدل جانشین و ارزش در معرض خطر شرطی)
   - ۲-۳-۱ تا ۲-۳-۵: لایهٔ پیش‌بینی (همان متن پیشین شاخهٔ `paper_TC`، به‌علاوهٔ لیانگ و لی ۲۰۲۴ از مراجع پروپوزال و CarbonCLIP ۲۰۲۶)
   - ۲-۳-۶ شواهد تجربی محدودیت تردد و قیمت‌گذاری ورود
   - ۲-۳-۷ یادگیری تقویتی در مدیریت ترافیک و سیاست‌گذاری شهری (از جمله لی و همکاران ۲۰۲۵، مرجع پروپوزال)
   - ۲-۳-۸ ارزیابی یادگیری تقویتی در برابر سیاست‌های ساده
   - ۲-۳-۹ شبیه‌سازی پیش از اجرا، مدل‌های جانشین و تصمیم‌گیری در عدم قطعیت
   - ۲-۳-۱۰ تهران (به‌علاوهٔ پژوهش‌های سیاست ترافیکی تهران)
   - ۲-۴ نتیجه‌گیری: شش شکاف و چهار پرسش
   - شکل ۱ (ماتریس شکاف در دو بخش: لایهٔ پیش‌بینی و لایهٔ تصمیم) و جدول ۱ (۳۷ مقاله)
3. **شماره‌گذاری دوبارهٔ همهٔ ارجاع‌ها** به ترتیب نخستین ارجاع (IEEE): ۱۲۷ منبع، ۱۰۶ منبع در فصل دوم. هر ارجاع فصل‌های ۳ تا ۵ پس از شماره‌گذاری به همان منبع پیشین اشاره می‌کند (بررسی خودکار).
4. **فهرست مطالب، اشکال و جداول** با عنوان‌های تازهٔ فصل دوم و شمارهٔ صفحه از یک خروجی PDF (لیبره‌آفیس). چون قلم‌های فارسی در لیبره‌آفیس جایگزین می‌شوند، شمارهٔ صفحه‌ها ممکن است کمی با Word فرق کند؛ فایل طوری تنظیم شده که Word هنگام باز شدن بپرسد فیلدها به‌روز شوند یا نه: **بله** بزنید.

فهرست همهٔ منابع، محل ارجاع و دلیل آوردن منابع تازه: `docs/thesis/references_notes_full.md`. فایل وارد کردن در Mendeley یا EndNote: `docs/thesis/references_ch2.ris` (۱۰۶ منبع فصل دوم).

## ساختن دوباره

پیش‌نیاز: Python 3 با Pillow، LibreOffice، Poppler (`pdftotext`)، Node با Playwright، و قلم Vazirmatn (`npm install vazirmatn`).

```bash
# 1) باز کردن فایل‌ها
mkdir -p build && cd build
unzip -q ../docs/thesis/thesis_chapters_3-5.docx -d full
unzip -q ../docs/thesis/thesis_chapters_3-5_RQ1-RQ2.docx -d rq12
# 2) اصلاح‌های داوری روی فایل کامل
python ../docs/thesis/ch2_source/port_review_fixes.py full rq12 full_fixed
# 3) شکل ۱
python ../docs/thesis/ch2_source/make_figure.py node_modules/vazirmatn/fonts/ttf figure1.html
node ../docs/thesis/ch2_source/shot.js "$PWD/figure1.html" figure1.png
python -c "from PIL import Image; Image.open('figure1.png').convert('RGB').save('figure1.jpg', quality=93)"
# 4) فصل دوم، شماره‌گذاری ارجاع‌ها، فهرست منابع و فایل RIS
python ../docs/thesis/ch2_source/build.py full_fixed final figure1.jpg references_ch2.ris ../docs/thesis/ch2_source/lit > build_log.json
# 5) فهرست مطالب: عنوان‌ها، سپس شمارهٔ صفحه از خروجی PDF
python ../docs/thesis/ch2_source/tocfix.py structure final
(cd final && zip -qXrD ../thesis.docx .) && soffice --headless --convert-to pdf thesis.docx
python ../docs/thesis/ch2_source/tocfix.py pages final thesis.pdf
rm thesis.docx && (cd final && zip -qXrD ../thesis_chapters_2-5.docx .)
# 6) یادداشت منابع
python ../docs/thesis/ch2_source/notes.py final references_notes_full.md build_log.json
```
